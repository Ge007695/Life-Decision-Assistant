# 生活决策助手 Life Decision Assistant

面向日常决策的规则引擎设计与实现——以深圳生活场景为例。

深圳大学学生创新发展基金基础实验项目（2026 年度），个人项目。

## 项目简介

把"数据公开但规则藏在专业术语里"的日常决策，统一翻译成一句话结论加可执行清单。四个场景：出门（晾晒、返潮、出行、穿衣）、时间（假期与调休）、花钱（实习到手工资、分期真实年化）、办事（证件材料清单）。

技术形态：纯前端静态站点 + 本地配置文件，无后端、无数据库、不采集个人数据。

## 计划中的代码结构

```
public/data/     配置层：指数权重、假期、税率、穿衣表
src/core/        内核层：引擎、规则、纯函数工具（禁止网络与 DOM）
src/services/    服务层：天气取数、缓存、本地存储
src/components/  组件层：结论卡、指数条等复用组件
src/modules/     业务模块：出门 / 时间 / 花钱 / 办事
scripts/backtest/  回测与实验脚本（Python）
docs/            设计说明书、决策记录、进度周志
```

## 两条开发纪律

1. `src/core/` 为纯函数层，禁止出现 `fetch`、`window`、`document`、`localStorage`。回测脚本直接引用同一份规则代码，保证"线上跑的模型"与"报告里评的模型"是同一个。
2. `main` 为可运行分支，推送即部署。大改动先开分支验证，通过后合并。

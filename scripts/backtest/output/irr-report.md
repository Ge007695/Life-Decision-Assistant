> 本表中的年化由线上同一份规则代码算出，不是 Python 复写的公式。

## 四、边界输入

| 场景 | 是否降级 | 结论 | 出现 NaN |
|---|---|---|---|
| 0 期 | 是 | 无法计算真实年化：期数必须是大于 0 的整数 | 无 |
| 负本金 | 是 | 无法计算真实年化：本金必须是大于 0 的数字 | 无 |
| 费率 0（应为 0 成本） | 否 | 真实年化 0%，名义费率 0% | 无 |
| 360 期（浮点误差） | 否 | 真实年化 10.47%，高于名义 7.2% | 无 |
| 非整数期数 | 是 | 无法计算真实年化：期数必须是大于 0 的整数 | 无 |

边界用例的判据是「有没有中文原因」与「有没有把 NaN 递给页面」，不参与一致性统计——算不出结果时，给出原因比给出数字更重要。
